# VuelosClaim

Calculadora gratuita de compensaciones por retraso, cancelación u overbooking de vuelos: https://vuelosclaim.eu

- `fuente/`: código que genera la web. Instrucciones en [fuente/README.md](fuente/README.md).
- `docs/`: web generada; es la carpeta que publica GitHub Pages.
- `.github/workflows/validar.yml`: validación automática de cada PR.
